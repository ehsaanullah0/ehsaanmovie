# CHANGELOG

## v1.5.0
- Added a refresh button (dark brown) to the Explore Hub to easily fetch new recommendations.
- Increased recommendation display capacity to 50 items per page with pagination navigation.

## v1.4.0
- Transformed recommendation section into an "Explore Hub" powered by TMDB.
- Recommendation section now shows trending movies and series not yet in the user's collection, allowing for deeper exploration and discovery.

## v1.3.0
- Updated "Where to Watch" modal to be light/dark theme-aware.
- Started removing yellow accent colors from non-essential UI elements to improve color scheme consistency.

## v1.2.0
- Replaced sidebar with bottom navigation bar in mobile and tablet view.
- Redesigned home page with a Netflix-style OTT hero slideshow banner and auto-rotation.
- Styled movie count metrics banner in lite brown instead of black.
- Added recommendation section below continue watching with a pilled yellow filter button (Type, Genre, Region, IMDb rating) and pagination arrows for 50+ titles.
- Added pre-loaded default starter backup catalog with 50+ movies and series.
- Shifted title lower in preview window for better visual presence and layout balance.
- Upgraded "Add to Queue" button with a 3-step cycle (Pending -> Watching -> Watched).
- Added "Add to list" option in every media preview window.
- Replaced external browser "Where to watch" with a gorgeous in-app streaming platform window.
- Styled movie progress sliders and tiny UI character elements with vibrant yellow accents.

## v1.1.0
- Added filter collapse/expand functionality for the Collection view to improve focus.
- Fixed light theme styling inconsistencies in UI components.
- Introduced theme color selection in Settings (neutral, stone, slate, zinc).
- Persist theme color settings in local storage.
- Improved CSS variable usage for accent colors.
- Updated JSON import/export to include new theme configuration.
- Cleaned up duplicate section styling in Settings view.
- Moved the close (X) button to the right side, next to the favorite (heart) button, in the Media Detail modal for better UI consistency.
- Added Backdrop Opacity Slider in Settings.
- Added "Select All" button and improved batch deletion.
- Improved text contrast in Media Details modal.
- Shifted title lower in media detail modal for improved visual balance.
- Darkened the yellow color of the IMDb rating badge.
- Added "Rand. Movie", "Rand. Series", and "Rand. Both" buttons to HomeView.
- Added a close arrow icon to the sidebar on mobile screens for better UX.
